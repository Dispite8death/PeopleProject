ПОКЕМОН — ЧЁТКИЕ СНИМКИ ДЛЯ ПРЕЗЕНТАЦИИ

Снимки заново получены из исходников приложения в браузере Chromium.
Плотность: 3 физических пикселя на один CSS-пиксель по каждой оси.
Формат: PNG без потерь, без промежуточного JPEG.
Старые изображения не увеличивались и не перерисовывались нейросетью.

СОДЕРЖИМОЕ
01–09: девять основных кадров, соответствующих исходному сценарию.
details/: два крупных фрагмента таблиц для презентации.
full/: восемь кадров окна браузера с окружающим интерфейсом;
мобильный кадр в корне уже содержит всё окно.
capture.mjs: сценарий повторной съёмки с Playwright.
manifest.json: размеры, область съёмки, версия браузера, проверки и хеши.
demo-state.json: вымышленное состояние демонстрации после сценария.

ПРИ ПРОСМОТРЕ И ВСТАВКЕ В ПРЕЗЕНТАЦИЮ
Сохраняйте пропорции и вставляйте исходный PNG из архива.
Для текста и фамилий используйте кадры из details/.
Изображение можно уменьшать до размеров слайда. Увеличение свыше его
физического размера снова потребует интерполяции.

ПОВТОРНАЯ СЪЁМКА ДЛЯ CODEX
Нужны Node.js, Playwright и установленный для него Chromium:
  npm install playwright
  npx playwright install chromium
  node capture.mjs "C:\путь\к\ПОКЕМОН" "C:\путь\к\новым-кадрам"
Скрипт запускает временный сервер только на 127.0.0.1 и использует свежий
профиль браузера. Настройки и данные рабочего проекта не меняются.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Проверены все PNG, визуально просмотрены девять основных кадров.
В итоговом отчёте проверены 3 ответа: 2 согласия, 1 отказ.
JavaScript-ошибок при успешном проходе сценария не обнаружено.
Это снимки демонстрационного интерфейса, не проверка PHP-бэкенда.

Использованы ранее переданные исходники проекта. Шаблон получил публичную
конфигурацию demo через вспомогательный сервер; PHP, nginx и БД здесь
для съёмки не запускались. HTML/CSS/JS приложения не изменялись.
Из-за Linux системный шрифт и вид встроенных полей даты отличаются от Windows;
заданные значения дат и времени те же. Области кадрирования уточнены по
границам элементов, поэтому размеры не являются точным утроением старых PNG.
